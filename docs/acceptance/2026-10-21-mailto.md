# mailto: 外部開啟（2026-10-21）

狀態：`VALIDATING`。比照凍結 Python 的 `URL.is_external`／`open_external`。

## 行為

- 地址列送出 `mailto:`（含前後空白）、左鍵點擊 mailto 連結：交給外部開啟器，不導覽、不改
  history、不送請求；URL 為序列化結果（去掉 fragment）；地址草稿依既有規則丟棄或保留。
- 點擊 listener `preventDefault` 的 mailto 連結不開啟。
- 表單 action 為 mailto 時仍是一般導覽，載入固定的「External mail link」頁並加入 history。
- 使用者決定（2026-10-21）：只用 `xdg-open`、點擊不先詢問。差異紀錄見 `PORTING_PLAN.md`
  「地址與外部開啟」列。

## 剩餘缺口

- 中鍵點 mailto（Python 會外部開啟）：native 尚未移植中鍵開新分頁。
- 每次開啟用一條 detached thread 等待子程序；卡住的開啟器會讓 thread 一直留著，沒有上限。
- 需要 glibc 2.34 以上（`posix_spawn_file_actions_addclosefrom_np`）。
